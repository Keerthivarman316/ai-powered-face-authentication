# Deployment

This project is configured as a single Docker-based Render web service.

## Architecture

Browser
→ FastAPI + static frontend
→ InsightFace + MiniFASNet PAD
→ SQLite database on a persistent Render disk

## Render configuration

The repository includes `render.yaml`.

- Region: Singapore
- Runtime: Docker
- Health check: `/health`
- One instance
- Persistent database disk mounted at `/app/database`
- `FACE_AUTH_API_KEY` is generated by Render
- Browser demo session uses an HttpOnly cookie

## Important

`PUBLIC_DEMO_MODE=true` is intended for a controlled demonstration. It means the browser demo can obtain a session without a separate user login. Do not treat this as production customer authentication.

Before production use, replace the demo session with real customer/application authentication, add consent and biometric retention controls, and calibrate the face-match/PAD thresholds against representative data.

The old API key that was previously committed to the public repository must be considered compromised and rotated. Never put a new API key in frontend JavaScript.

## Local development

Create `.env` from `.env.example`, set `FACE_AUTH_API_KEY`, and run:

```bash
uvicorn api.main:app --reload --port 8000
```

For the existing frontend dev server on port 5500, the frontend automatically targets the FastAPI server on port 8000.
